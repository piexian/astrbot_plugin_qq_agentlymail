# QQ Agently Mail

让你的 AstrBot 机器人用上 QQ 官方 Agent 邮箱：直接在聊天里收发邮件、搜邮件、下附件、开新邮件提醒，还自带管理面板网页邮箱「邮局」。

> [!TIP]
> 默认只有管理员可以在聊天中让机器人操作邮箱；如需开放给指定群聊或私聊，在插件配置里把聊天编号加入名单即可，无需额外绑定。

## 快速开始

1. **安装插件**
   - 方式一：在 AstrBot 插件市场搜索「QQ Agently Mail」，点击安装。
   - 方式二：插件界面右下角加号 → 从链接安装，输入：
     ```
     https://github.com/piexian/astrbot_plugin_qq_agentlymail
     ```
2. **扫码登录邮箱**
   - **网页登录（推荐）**：打开 AstrBot 管理面板 → 插件 →「QQ Agently Mail」→ 视图「邮局」，点击「扫码登录」用微信扫码确认即可。
   - **指令登录**：管理员也可在聊天里发送 `/agently login`，扫描机器人发出的二维码并在手机上确认；如果微信下有多个 Agent 邮箱，按提示回复序号即可。
3. **开始使用**
   - 登录完成后就可以直接用，试试跟机器人说「帮我看看最近有什么未读邮件」，或者直接在管理面板「邮局」里收发邮件。

运行要求：AstrBot `4.16` 及以上（`< 5`），无需额外安装依赖。

## 账号与会话访问控制

在插件配置里可以按聊天范围控制谁能让机器人收发邮件；在目标群聊或私聊发送 `/sid` 即可拿到该聊天的编号。

| 设置方式 | 普通用户 | 管理员 |
|----------|:--------:|:------:|
| **白名单**（默认）且名单为空 | 用不了 | 任意聊天可用 |
| **白名单**且填了聊天编号 | 仅名单内的聊天可用 | 任意聊天可用 |
| **黑名单**且名单为空 | 所有聊天可用 | 所有聊天可用 |
| **黑名单**且填了聊天编号 | 名单外的聊天可用 | 名单外的聊天可用 |
| 登录、登出、删邮件、改地址等管理操作 | 用不了 | 可以用 |

关于账号与登录凭证：

- 放行后的聊天默认使用 `default` 账号；管理员如果登录了多个账号，也可以直接在对话中指定要操作哪一个。
- 登录凭证保存在 `data/plugin_data/astrbot_plugin_qq_agentlymail/` 下并自动续期，相当于登录密码，请勿分享给他人。
- 凭证失效时，在「邮局」页面重新扫码或发送 `/agently login` 即可更新。

## 功能一览

插件为 AI 提供以下 3 个邮箱工具，由机器人按对话需要自动调用（可在 AstrBot 工具管理中单独启停）：

| 工具 | 能力说明 | 使用权限 |
|------|----------|----------|
| `agently_mail_read` | 查看邮箱与发信额度、浏览各目录邮件、阅读全文、下载附件、搜索邮件 | 放行聊天 / 管理员 |
| `agently_mail_send` | 发送新邮件（支持附件）、回复、转发、开启或关闭当前聊天的新邮件提醒 | 放行聊天 / 管理员 |
| `agently_mail_admin` | 扫码登录与登出、查看账号状态、删邮件与清空垃圾箱、新建或注销邮箱地址 | 仅管理员 |

补充说明：

- **邮箱地址**：新建地址的前缀由 QQ 邮箱自动生成，无法自定义；注销地址会清空该地址下所有邮件且不可恢复（90 天内再新建会复用原地址）。
- **附件限制**：发信附件单件与总大小均不超过 20 MB、最多 50 个；下载的附件会保存在 AstrBot 临时目录中。

## 指令用法

以下命令无需经过 AI，直接在聊天里发送即可（均**仅管理员可用**）：

```
/agently login            # 微信扫码登录（默认账号 default）
/agently login work       # 登录另一个账号并命名为 work
/agently logout           # 退出默认账号并停止它的新邮件提醒
/agently logout work      # 退出 work 账号
/agently status           # 查看已登录账号与当前聊天的访问权限
```

二维码有效期约 2–3 分钟；如果扫码图无法发出，机器人会自动附带备用授权链接和验证码。

## 在对话中使用

登录后直接像平时聊天一样跟机器人说就行：

- 「看看收件箱里最近 5 封未读邮件」
- 「把第二封邮件的内容读给我，顺便把附件下下来」
- 「搜一下标题里带验证码的邮件」
- 「给 alice@example.com 发封邮件，通知今晚八点开会」
- 「帮我开启新邮件提醒」／「关闭新邮件提醒」

开启新邮件提醒后，收到新邮件会自动推送到当前聊天；重启 AstrBot 后也会自动恢复监听，无需重新开启。

## 邮箱 WebUI（邮局）

管理面板 → 插件 →「QQ Agently Mail」→ 视图「邮局」，打开即可当网页邮箱用，会自动跟随 AstrBot 面板的语言（简体中文 / English / 日本語 / Русский）和深浅色主题。

| 功能 | 说明 |
|------|------|
| 扫码登录 | 页面内直接展示微信二维码，附带可一键复制的原链接和验证码，支持刷新、多邮箱选择与随时取消 |
| 账号与地址切换 | 快速切换不同账号及名下多个邮箱地址，凭证过期时可直接重新扫码 |
| 目录与搜索 | 浏览收件箱、已发送、垃圾邮件、垃圾箱，支持只看未读、翻页与关键词搜索 |
| 读信与下载附件 | 查看完整邮件内容，一键下载附件到本地 |
| 写信／回复／转发 | 在线写信（支持多附件，总大小 ≤ 20 MB）、回复或转发，发送前弹出确认防止误发 |
| 邮件与地址管理 | 移入垃圾箱、查看可用地址数量上限、新建或注销邮箱地址 |
| 额度信息 | 查看当前账号的发信限额、今日已发次数与附件限制 |

说明：网页邮箱需先登录 AstrBot 管理面板才可访问，发信同样遵守插件配置里的「允许发信的邮箱」限制。

## 配置说明

在 AstrBot 管理面板 → 插件配置中修改：

| 配置项 | 面板名称 | 默认值 | 说明 |
|--------|----------|--------|------|
| `umo_filter_mode` | 可用聊天范围 | 白名单 | 白名单下仅管理员和名单内聊天可用；黑名单下除名单内聊天外均可用 |
| `umo_filter_list` | 聊天名单列表 | 空 | 填写允许或屏蔽的聊天编号（在对应群聊或私聊发送 `/sid` 获取） |
| `mail_send_whitelist` | 允许发信的邮箱 | 空（不限制） | 仅允许给列表中的邮箱发信、回复或转发，留空表示不限制，聊天和网页邮箱同时生效 |

## 安全说明

- **管理权限隔离**：所有 `/agently` 指令和删除邮件、注销地址等管理操作均仅限管理员使用；未放行的聊天无法读取或发送邮件。
- **收件人白名单**：配置「允许发信的邮箱」后，无论是 AI 发信还是网页邮箱发信（含抄送、密送和回复），都会拦截名单外的收件人。
- **防恶意邮件干扰**：邮件正文与标题、发件人、附件名在交给 AI 前会做隔离和清洗，降低恶意邮件诱导机器人误操作的风险。
- **本地文件与凭证保护**：AI 发信只允许附带 AstrBot 临时目录内的文件，不会读取服务器其他文件；账号凭证独立保存并设为仅当前用户可读，日志中不输出登录凭据。
